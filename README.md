# <img src="./program_info/org.unmojang.FjordLauncher.svg" alt="Fjord Launcher logo" width="96"/> Fjord Launcher Unlocked

notmojangstudioslauncher is a **fork** of Fjord Launcher Unlocked, which is a fork of Fjord Launcher, which is a fork of Prism Launcher. It is **not** endorsed by nor affiliated with Fjord Launcher Unlocked or Fjord Launcher or Prism Launcher.

## Advantages of this fork over other launchers

- Custom authentication server (free accs)

- No requirement for a real Mojang Account

- Ability to download FTB modpacks from within the launcher
